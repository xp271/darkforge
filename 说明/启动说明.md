# 暗黑重铸（Darkforge）· 启动说明

## 这个文件夹是什么

`darkforge\` 是一个**整合启动包**，在**原版游戏**上改，不改游戏目录里的任何文件：

- `launcher\` —— 启动器（图形界面）、重随脚本（`launcher\reroll\`）、自带的 Python 和 .NET
- `randomizer\` —— 敌人随机用的随机器 EldenRingRandomizer v0.12.2（thefifthmatt），随机化输出也写在这里。以后整合包不再自带它（它的许可不许转发），
  要自己从 https://www.nexusmods.com/eldenring/mods/428 下载 v0.12.2，把压缩包里的东西全部解压到这个文件夹（解压好后这里直接就是 `EldenRingRandomizer.exe`）。
  没装时启动器不开放敌人随机（相关按钮会说明怎么装），「无敌人随机」照常能玩：原版文件从你自己的游戏里取
- `yafsml\` —— YAFSML 注入式加载器
- `dll\` —— 整合包自带的 DLL（dark_core / dark_sell / dark_lock / dark_wings 等），也可以放自己的 DLL mod
- `out\` —— 每次启动生成的覆盖包（不用管，删了会重新生成）
- `说明\`、`更新日志.txt`、`启动.bat`

## 怎么启动

**双击 `启动.bat`**，打开图形界面：

| 按钮 | 作用 |
|---|---|
| 一键启动（无敌人随机） | 在原版上生成重随包后启动 |
| 一键启动（敌人随机） | 在最近一次随机器输出上生成重随包后启动；还没有随机器输出时先自动随机化一次 |
| 一键重随敌人 | 换一个新种子重新随机化敌人，不启动游戏（约 2~5 分钟） |
| 打开随机器，自己配置敌人 / 物品随机 | 先弹出操作步骤：勾「敌人随机」，「物品随机」可开可不开（见下面「自己配置随机器」），「合并其它MOD」留空 |
| 游戏路径 | 设置游戏目录 |
| 备份存档 / 恢复存档 | 备份 / 恢复 `.rng` 存档（联机的 `.rng.co2` 也算）和角色记录（见下面「启动前自动备份 / 恢复」） |
| 重随设置 | 用记事本打开 `launcher\reroll\settings.json` |
| 一次性重随 | 骨灰的位置、开局装备、开局遗物只在第一次启动时抽一次；点这里后，下次启动会重新抽（之后再固定；已有角色手上的开局装备也会跟着变）。用敌人随机启动时如果还没有暗黑重铸存档（新开局），启动器会自动先做一次，种子用当前电脑时间 |
| 联机 | Seamless Co-op 联机（测试中）：联机启动、复制 / 导入联机随机码（见下面「联机」） |
| 报告 / 日志 | 打开上次重随报告和 YAFSML 日志 |
| 导出诊断包 | 出问题时把日志、配置、崩溃记录打成 zip 放到桌面，发给帮你排查的人 |
| 常见问题 | 怎么重新随机敌人、怎么回退版本、自动备份在哪；更新后想沿用旧版本的敌人随机结果也在这里 |
| 更新日志 | 打开「更新日志.txt」 |

- 启动过程的输出显示在窗口下方；游戏启动后可以关掉这个窗口。
- **启动前要先在游戏里正常退出**（系统 → 退出游戏）：启动时可能要重新生成覆盖包，游戏开着时不能覆盖它正在用的文件。

## 每次启动做什么

启动前先花几秒生成两个覆盖包，YAFSML 按顺序加载（后面的覆盖前面的）。**原版文件、随机器输出、存档都不会被改动。**
设置、整合包、随机器输出、一次性重随记录和游戏版本都没变时，重随包直接沿用上次的（几秒），有一样变了才重做（约 20 秒）；启动日志里会写「输入没变，沿用上次的重随结果」或者哪一样变了。

1. **`out\reroll\`**（`launcher\reroll\reroll.py`，在原版或随机器输出的 regulation 上改）：
   - 敌人血量按地区加（`enemy_hp_band`，6 档）；开了敌人随机时按敌人实际被放到的位置算（`enemy_hp_align`），改过的地图写在 `out\reroll_maps\`；
   - Boss 战里召唤 / 生成的随从不掉东西；所有粪金龟血量统一（`scarab_hp`）；
   - 骨灰在原来的获取格之间打乱（`spirit_ashes_shuffle`，一次性重随，结果记在 `%APPDATA%\EldenRing\DarkReforged\角色记录\once.json`）；
   - 每个 Boss 多给 1 个龙心脏和 1 个星光碎片（`boss_heart_shard`），保底给所在地区的锻造石（`boss_smithing_stone`）；
   - 开局：送召魂铃（`start_spirit_bell`）、灵马哨笛、能直接在赐福升级（`start_torrent` / `start_level_up`）；
     职业的开局武器 / 防具换成生成的装备（`start_gear`，词条由 `dll\dark_core` 生成）、9 个开局遗物换成会放法术的稀有护符（`start_keepsakes`），都是一次性重随；
   - 暗黑商店的护符 / 武器 / 魔法 / 祷告 / 道具商店（`dark_shop`）；
   - 地下墓地、洞窟等不用先打 Boss 也能传送（`fast_travel_anywhere`）；不受坠落伤害（`no_fall_damage`）；
   - 双子老妪不限量卖卢恩弯弧（`twin_rune_arc`）；战技的固定伤害部分 ×1.3（`skill_flat_damage_mult`）；赐福记忆不丢卢恩（`memory_of_grace_keep_runes`）；
   - 局内难度（`difficulty`）、庆典油脂（`festive_grease`）、训练木桩（`training_dummy`）用到的参数。
2. **`out\scripts\`**（`launcher\reroll\scripts.py`，赐福脚本、公共事件、玩家动作脚本这些随机器输出也会改的文件，在前面最后生效的那份上合并）：
   赐福「更多选项」和头目复活、局内难度菜单、一键出售、双子老妪子菜单、装备锁定的菜单文字、开局发东西的事件、
   蹬墙跳（`wall_jump`）、不会摔死、灵马速度（`torrent_speed`）、商人对话里直接拿铃珠（`merchant_bell_bearings`）、圆桌厅堂的训练木桩。
   合并失败时只是这次没有这些，照常启动。

开关和数值都在 `launcher\reroll\settings.json`（每项后面以 `_` 开头的是说明）。每次生成的结果写在 `out\reroll\reroll_report.txt`。

## 新装备系统（未鉴定物品 → 赐福一键鉴定）

- 「未鉴定」的武器 / 防具 / 护符是额外的掉落（原版掉落、宝箱、商店照旧），来源照以前 RNG 装备的设定：
  - 普通敌人每杀平均 0.67 件（`enemy_drop_chance` 0.6、`enemy_material_share` 0.25 换算），稀有度按地区（`tier_bands` 的 `weights`）；
    精英按下一个地区，DLC 后期的精英再平均多 `elite_last_legendary_mean` 件传说；
  - Boss 击杀奖励多给 `tier_bands` 各档 `boss_legendary` 件传说（1 / 2 / 3 / 5 / 6 / 8），只给一次；
  - 每个宝箱追加一件（`chest_rarity_weights`：传说 25%、史诗 75%）；黄金卢恩【1】~【13】光点换成未鉴定物品（`golden_rune_to_gear`）；
    人形 NPC 死后多掉一件传说（`npc_add_legendary_if_no_gear`）；武器 / 防具 / 护符按 `gear_category_share`（30 / 60 / 10）。
- 在赐福选「一键鉴定」：背包里的未鉴定物品一次全部变成随机生成的装备（每批最多 32 件，多的接着发）。确认框里会显示背包里有几件、
  每类还能放多少件。生成要 `dll\dark_core\dark_core.dll`，词条库在 `launcher\reroll\data\affixes\`。
- 一个角色同时最多拿着武器 3000 / 防具 6000 / 护符 600 件生成的装备（`containers`，背包 + 仓库合计）；卖掉、丢掉就空出来。
- 每个角色鉴定出来的装备记在 `%APPDATA%\EldenRing\DarkReforged\角色记录\items_<存档格子>.txt`，进存档时按它重建；启动前备份、恢复存档都带着它。
  删掉这个文件，那个角色身上的生成装备会变回没改写的样子。

## 装到其他电脑

1. 把压缩包解压到任意位置（放在游戏的 `Game` 文件夹里最省事，启动器会自动找到游戏）；路径别太深，太深会超出 Windows 的路径长度上限；
2. 双击 **`启动.bat`**；找不到游戏时会让你选一次游戏目录；
3. 第一次启动（或游戏更新后）进标题画面会慢一些：YAFSML 在边玩边建缓存，之后就快了。

- 需要：Windows 10/11、正版 ELDEN RING（含 DLC；做的时候用的是 1.17.1 / eldenring.exe 2.7.1.0，DLL 功能也认 1.17.2 / 2.7.2.0）。
  Python 和 .NET 都自带，**不用装任何东西**；不用 Mod Engine。
- 存档在 `%APPDATA%\EldenRing\<SteamID>\ER0000.rng`；整合包自己的东西都在旁边的 `%APPDATA%\EldenRing\DarkReforged\` 里，都不在整合包里：
  `角色记录\`（装备配方、锁定名单、免费许愿次数、一次性重随）、`启动前备份\`、`旧文件\`（不再使用的旧版文件，可以删）。
  **要把自己的存档一起带过去，就把整个 `%APPDATA%\EldenRing` 文件夹拷过去**。整合包本身可以随便换目录、重新解压、更新。
- 包里**没有**这些（都会自动重新生成）：`out\`、`yafsml\YAFSML.ini`、游戏路径的记录、缓存和日志、随机器输出（第一次玩敌人随机时会先自动随机化一次）。

## 游戏路径（第一次启动选一次，不用手改文件）

启动器按下面顺序找游戏：

1. 读 `launcher\game_path.txt`（上次选择 / 自动检测后保存的路径）；
2. 自动检测：Steam 库（`steamapps\common\ELDEN RING`）、整合包附近的 `ELDEN RING*` 目录、常见安装目录；
3. 都找不到（或找到多个）时，会让你选。

手动更换：图形界面点「游戏路径」。
选什么都会换算成包含 `Game` 子目录的那层，保存到 `launcher\game_path.txt`。

## 一键重随敌人

图形界面点「一键重随敌人」：换一个**新种子**重新随机化敌人，约 2~5 分钟，完成后点「一键启动（敌人随机）」玩。
- 随机器窗口会自动打开、自动点「随机化敌人」、完成后自动关闭——**这期间不要点随机器窗口，也不要关掉它**；
- 第一次玩敌人随机时不用先点这个按钮：直接点「一键启动（敌人随机）」会先自动随机化一次再启动，随机化失败就不启动；
- 用哪份随机器设置：**在随机器里改过 / 用过就按上一次的设置**（每次都勾「重roll种子」，由随机器自己换新种子）；从没用过随机器就按整合包默认（只开敌人随机，物品随机要自己在随机器里开）；
- 不合并别的包：「合并其它MOD」每次都清空（以前的版本会填可玩包的路径；那样做出来的随机器输出带着别的包的参数，启动器认得出来，会要求先重新随机化）；
- **前期少放精英、越往后越多**（`elite_share_by_band`，前期 2.5% → DLC 后期 15%）：随机化前往随机器的自定义敌人预设（`randomizer\presets\CustomEnemy.txt`）里写指定，并打开随机器的「自定义敌人」选项；古龙（`early_ban_models`）前期一律不放。精英名单在 `launcher\reroll\data\elite_families.json`（本体）和 `elite_dlc.json`（DLC），列表见「精英敌人列表.txt」；
- **追忆 Boss 只在追忆 Boss 之间打乱**（`remembrance_boss_shuffle`）：本体和本体换、DLC 和 DLC 换（狂龙贝勒虽然不掉追忆，也算在 DLC 这边）；
- 有的种子随机器自己会失败，会自动换种子再试，最多 3 次；旧的随机结果会被覆盖（`randomizer\spoiler_logs` 里的旧日志还在）。
- 命令行：`launcher\python\python.exe launcher\df.py randenemy`（加 `--dry-run` 只显示会用哪份设置）。

## 自己配置随机器

图形界面点「打开随机器，自己配置敌人随机」，在随机器窗口里：
1. 第一次使用：点「选择游戏exe启动文件」选好 `eldenring.exe`；
2. 「合并其它MOD」留空；
3. 勾选「敌人随机」，按喜好调整；
4. 「物品随机」可开可不开。开了会打乱法术祷告、道具、材料、锻造石的位置和商人货架；原版武器、防具、护符整合包照样换成未鉴定物品，
   整合包加的 Boss 奖励、未鉴定掉落、暗黑商店、追忆换取的传说不受影响；关键道具要不要打乱看「物品随机」里关键道具那一项。
   重随会认出开了物品随机：随机器已经打乱过的商店、骨灰不再打乱（详见 `dev\item_rand\物品随机兼容.md`）；
5. 点「随机化敌人」（开了物品随机是「随机化物品与敌人」），完成后关掉随机器（不要点它的「启动游戏」），回启动器点「一键启动（敌人随机）」。

在这里改过的设置，以后「一键重随敌人」也会沿用。

## 加其他 DLL mod

把 DLL mod 放进整合包根目录的 `dll\` 文件夹，每次启动生成 YAFSML 配置时会自动加进 [dll]：
- `dll\某mod.dll` 直接放；mod 带配置文件时整个文件夹放进来（`dll\某mod\某mod.dll`，只看这一层）；
- 文件名或文件夹名以 `_` 开头 = 停用；按路径字母顺序加载；
- 不要直接改 `yafsml\YAFSML.ini`，它每次启动都会按 `launcher\YAFSML.ini.tpl` 重新生成；
- 只放 DLL 类 mod，改 regulation 或游戏数据的 mod 会和整合包冲突；
- 会另外改存档文件名的 DLL（alt_saves 类）不加载；Erd Tools 的 `save_extension` 启动器按启动方式自动改：单机 `rng`、联机 `co2`。

## 启动前自动备份 / 恢复

每次启动游戏前，启动器会把暗黑重铸存档（`ER0000.rng`，联机的 `ER0000.rng.co2`）和角色记录（`DarkReforged\角色记录\` 里的文件，联机的在 `角色记录\联机\`）复制一份到
`%APPDATA%\EldenRing\DarkReforged\启动前备份\<时间>_启动前\`，留最近 10 份（内容没变就不重复存）。
（2026-10-29 以前这些文件散在 `%APPDATA%\EldenRing` 根目录：`DarkReforged_*.txt`、`DarkReforged_启动前备份\`、旧版的 `RNGLands_*`，启动器第一次启动时自动搬进 `DarkReforged\`，旧备份照样能恢复。）

「恢复存档」：
- 默认恢复到**上次启动前**；点「手动选择…」可以从所有备份里挑（启动前、恢复前、「备份存档」按钮存的）；
- 存档和角色记录一起换回去，那之后的游戏进度会丢失（启动前备份是开游戏之前存的，所以上次玩的整段都会丢）；确认框会列出每个角色恢复前后的等级和游戏时间；
- 只是遇到问题的话，先点「导出诊断包」，不用恢复；
- 恢复前会先把现在的存档和记录存成「恢复前」备份，恢复错了还能再选它换回来。

「备份存档」存到整合包里的 `存档备份\<时间>\`，结构一样，「恢复存档」→「手动选择…」能选到。

## 赐福「更多选项」（移植自 ELDEN VINS）

赐福菜单「离去」上面多了「更多选项」：购买和卖出（收在「双子老妪」子菜单里）、铃珠交易 1~4 和幽影之地（把铃珠交给双子老妪后，在任意赐福买那位商人的东西）、强化武器、调灵、复制战灰、从追忆获得力量、获得英雄的防具、龙飨仪式、头目复活、重新诞生（仍要幼虫之泪）、化妆。我们自己的功能都收在赐福菜单最上面的「暗黑重铸」里：一键鉴定（见上面「新装备系统」）、装备工坊、向星辰许愿、暗黑商店、一键出售（按类别、稀有度卖背包里生成的装备，装备着的、锁定的不卖）、武器回收、难度调整和「暗黑重铸说明」（按主题讲整合包的各项机制，文字在 `launcher\reroll\data\guide.json`；开局送的说明书只剩一本欢迎说明）。
- 都是原版的界面和商店行，解锁条件和原版一样；
- 没有移植 VINS 自己的难度强度系统和地图标记开关；
- **头目复活**（Vawser 的 Boss Resurrection - Lite）：选地区 → 选 Boss，能看到存活 / 已死亡；选「复活」后要**打开地图传送到赐福**（或真正重新进入该区域）才会完整重置、可以再打。免费；只是清掉 Boss 的击败标记。
  - 注意：复活后**只在原地「在赐福休息」不一定够**——休息会刷新怪物，但不会重新载入整张地图。带阶段 / 幻影的头目（如「死亡」以上的双月骑士蕾拉娜）这样重打会出现「Boss 倒下但血条不消失、Boss 战结束不了」。遇到这种情况，打开地图传送到赐福再回来即可。
  - 不要在 Boss 战场里出现的赐福复活这个 Boss（会卡战斗）；剧情 Boss 复活后相关 NPC 事件不会重来；
- **难度调整**（在「暗黑重铸」里）：8 档（`difficulty`，轻松 ~ 不可能），随时切换，存进存档，没选过就是原版；只改玩家造成 / 受到的伤害和卢恩、发现力加成，不改敌人 AI。

## 更新整合包（从旧版本换到新版本）

把新版本解压到一个新文件夹（不要覆盖旧文件夹），打开图形界面会弹一次更新说明：
1. 关掉旧版本，以后只用这个新版本启动；
2. 玩敌人随机的：**旧版本的文件夹先别删**。启动器会问你要不要沿用旧版本的敌人随机结果（约 100 MB，几秒钟复制完），
   选「是」敌人就和之前一样，接着玩；选「否」的话，第一次点「一键启动（敌人随机）」时会重新随机化一次（约 1~5 分钟，期间不要碰随机器窗口），
   之后不再问（想沿用：「常见问题」里点「沿用旧版本的敌人随机」，要在重新随机化之前）；
   - 怎么找旧版本：每次启动游戏时启动器会把整合包的位置记到 `%APPDATA%\EldenRing\DarkReforged\packs.txt`；
     v0.8.5 以前没记，就在新文件夹的上一级、上两级目录往下两层里找（解压到旁边的文件夹都能找到）；
   - 只沿用 v0.7 及以后、开了敌人随机、没合并别的包的结果；有好几份挑随机化时间最新的；
   - 新文件夹的随机器还没用过时，「一键重随敌人」也沿用旧版本随机器里的设置；
3. 改了什么见「更新日志.txt」。遇到问题先点「导出诊断包」；「恢复存档」会丢掉上次启动之后的进度，只在确实想回退时用。

## 联机（Seamless Co-op，测试中）

整合包不带 Seamless Co-op，要自己下载：把压缩包里的 `SeamlessCoop` 文件夹整个放进整合包的 `dll\`（变成 `dll\SeamlessCoop\ersc.dll`；
压缩包里的 `ersc_launcher.exe` 不用，联机也从整合包的启动器启动）。游戏目录里已经有 `Game\SeamlessCoop\` 的也能用，两边都有时用 `dll\` 里的。
平常启动不加载它，只有点「联机」里的联机启动才加载。

两个人的游戏数据要完全一样：
1. 同一个版本的整合包、同样的 `settings.json`；
2. 玩敌人随机：一人点「联机」→「复制随机码」发给队友，队友复制后点「联机」→「导入随机码」（按随机码重随敌人，约 1~5 分钟；已经一样就不重随）；
3. 两人都点「联机 · 敌人随机」（或者都点「联机 · 无敌人随机」）。联机启动时重随用联机种子（敌人随机 = 随机器的种子，无敌人随机是固定的），
   商店、骨灰位置、开局装备等两边一样；运行日志里的「联机核对码」两人应该一样；
4. `ersc_settings.ini` 的 `cooppassword` 两人填一样的。Seamless Co-op 的随人数加血会叠在整合包的敌人血量上，主机觉得太肉可以调低 `boss_health_scaling`、`enemy_health_scaling`。

- 联机存档是 `ER0000.rng.co2`，和单机存档分开；联机角色的生成装备、锁定、免费许愿记录在 `角色记录\联机\`，
  一次性重随的记录是 `角色记录\联机\once_<种子>.json`；启动前备份、恢复都带上它们。
- 已知问题：队友身上的生成装备在你这边可能显示不对（名字、外观）。
- 命令行（调试用）：`launcher\python\python.exe launcher\df.py coop / coopvanilla / coopcode / coopimport`。

## 存档

- 独立存档：`%APPDATA%\EldenRing\<SteamID>\ER0000.rng`，联机存档 `ER0000.rng.co2`；原版存档 `ER0000.sl2` 互不覆盖
- 机制：YAFSML 的 `replace_save_filename=.rng`、`replace_seamless_coop_save_filename=.rng.co2` + `prevent_regulation_save_write=1`；
  `dll\ErdTools\erd_tools.ini` 里的 `save_extension` 启动器每次启动按启动方式写（单机 `rng`、联机 `co2`）

## 日志 / 排障

**出问题时：图形界面点「导出诊断包」，把桌面上生成的 `Darkforge_诊断_时间.zip` 发给帮你排查的人。**
里面有：YAFSML 日志和配置、重随报告、最近 10 次启动器运行日志、每局游戏怎么结束的、各项设置、角色记录、随机器日志开头、
系统 / 游戏版本 / Python / 缓存状态、CPU / 显卡 / 显卡驱动、正在运行的画面层程序、游戏目录里的 DLL、dll 文件清单，
最近 7 天 Windows 里和游戏有关的崩溃记录和显卡驱动出错记录，以及从崩溃转储里取出的调用栈（`crash_stack.txt`）。不包含存档和转储文件本身。
超过 1 MB 的日志只带最后 1 MB（最近几次启动）。

- 启动器每次运行的完整输出（包括重随过程）自动存在 `launcher\logs\`，保留最近 30 份。
- 装备工坊界面（`dark_ui`）和敌人信息 mod 每次启动都会重写自己的日志，启动器在启动前把上一次的复制到 `launcher\logs\dll_runs\`（每种留最近 10 份）。
- 别的 DLL 日志（`dll\dark_*\dark_*.log`）每行开头是时间，每次加载先写一行 `==== 日期 加载（进程 N）`；
  一直往后追加的日志（这些 DLL 的、YAFSML 的、随机器 CrashFix 的）超过 2 MB 时，启动器在启动前把它挪成 `<文件名>.old`（只留一份）；
  幻化插件每天一个的日志（`dll\logs\`）只留最近 14 天。
- 每局游戏怎么结束的（正常退出 / 退出时崩溃 / 崩溃 / 卡住后被关掉，带退出码）记在 `launcher\logs\game_sessions.txt`，留最近 300 局；
  Windows 没记崩溃事件时，退出码是 0xC… 的也算崩溃。
- 存档操作（自动 / 手动备份、恢复、删旧备份、整理旧文件）记在 `launcher\logs\save_ops.txt`，留最近 300 行。
- 启动时跑的 Python 工具（重随、游戏脚本合并、菜单合成）的错误输出也写进运行日志；合并 / 合成失败时会显示最后几行报错。
- 启动器窗口自己出的错，关窗口时写进 `launcher\logs\gui_errors.txt`；窗口程序本身的出错堆栈在 `launcher\logs\gui_trace.txt`（每次打开重写）。
- **游戏崩溃、或者卡住（无响应）后被关掉时，会自动导出诊断包**到 `崩溃诊断\`（保留最近 10 个）并弹窗提示；正常退出不会打包。
  游戏带 mod 退出时常在 eldenring.exe+0x1ebb809（1.17.2 是 +0x1ebcef9）出错（存档已写完，没有影响），这种退出时的崩溃不弹窗，只记一行到 `launcher\logs\exit_crashes.txt`。
- YAFSML 日志：`yafsml\log\YAFSML.log`（一直往后追加，启动器每次启动前先写一行 `==== 时间 暗黑重铸 启动（方式）====`），健康的样子包含：
  ```
  INFO: [mod] added mod DR_Reroll from `...\darkforge\out\reroll`
  INFO: [mod] added mod DR_Scripts from `...\darkforge\out\scripts`
  ```
  敌人随机时前面还有 `DR_Randomizer`、`DR_RerollMaps`，以及 `[extdll] loaded external DLL randomizer_crashfix`。
- 游戏没启动：看日志；确认**不要用管理员身份运行**、游戏路径正确。
- **双显卡电脑**（核显 + 独显，笔记本常见）：敌人信息 mod（敌人头上的血条、状态条）在有的双显卡电脑上一启用，游戏的显卡设备就会丢失、读档时闪退，不是每台都会。
  检测到两块显卡时，第一次启动会弹窗问要不要加载它，选择记在 `launcher\reroll\state\enemy_info_mod.txt`（on / off）；
  加载着它游戏崩溃了，会问要不要改成不加载；图形界面「常见问题」里的「重选敌人信息 mod」清掉选择，下次启动再问。
  诊断包 `system.txt` 里有「敌人信息 mod」一行。
- 敌人刷出时崩溃：把 `launcher\dfl\launch.py` 里 `randomizer_crashfix=...|early` 改成不带 `|early` 试试。
